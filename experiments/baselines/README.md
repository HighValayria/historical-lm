# Baselines

本目录是**可控运行的接口契约**，不是模型结果目录。尚无获授权、可复现的模型接口；不得因本说明存在而推断任何模型已运行或任何方法有效。

## 最小兼容层（B1）

现有 `scripts/research_validity_pilot/run_openai_compatible.py` 可作为旧试点与后续严格年代评测之间的低风险适配层。它只接受冻结的 Prompt packet，默认干运行；非 loopback 端点须同时提供 `--execute --allow-remote`，并由操作者确认授权。它不会发现、修改或打印凭据，并以 append-only JSONL 保留原始响应。

| 条件 | 用途 | 允许状态 |
|---|---|---|
| P0 / E0 | 无时间约束、无证据的默认回答 | 配置或已运行 |
| P1 / E1 | 仅增加明确的截止时间约束 | 配置或已运行 |
| O0 / E2 | 仅提供核验 Oracle 证据 | 配置或已运行 |
| O1 / E3 | 截止时间与 Oracle 的正交联合条件 | 配置或已运行 |
| R0 | 普通 RAG（不作时间过滤） | 仅在语料和许可被单独冻结后配置 |
| R1 | 时间过滤 / 重排 RAG | 仅在时间元数据可核验后配置 |

旧 Data Feasibility Pilot 的 B0/B1/B2 与 Research Validity Pilot 的 E0/E1/E2/E3 均保留原文件、哈希和审计语义；不能把它们改名为已验证的时代错置评测。新评测只能通过题项层面的 `chronology_card_id`、独立命题组、截止点、行动者范围与证据清单接入，不得覆盖旧题目或原始输出。

真实运行前必须冻结：精确模型标识及版本、端点类型、生成参数、Prompt packet SHA-256、语料 / 检索索引版本、运行时间和原始输出位置。评分结果是派生物，须与 append-only 原始响应分目录保存。无授权接口时只可进行干运行与结构校验，绝不生成伪输出。

具体条件以正式实验协议为准；模型、版本、参数、Prompt 哈希和原始输出必须完整保存。
