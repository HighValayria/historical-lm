# T30 Node Report: Probe Real Data Access

## Objective

Probe real-world access to high-priority source candidates for the selected C1 benchmark direction.

## Dependencies

T21.

## Inputs

- `evidence/source_registry.md`
- `reports/recommended_direction.md`
- `probes/data_access/probe_sources.ps1`

## Actions

- Created a repeatable metadata-only access-probe script.
- Probed four selected source entry points:
  - `SRC-CUSTOMS-WELLCOME`
  - `SRC-CMMJ-CRL`
  - `SRC-SMC-BNASIE`
  - `SRC-CUSTOMS-AS`
- Saved processed results in `probes/data_access/access_probe_results.json`.
- Saved response metadata, headers, titles, content lengths, and hashes under `data/raw/access_probe/`.
- Did not persist response bodies or perform bulk downloads.

## Actual Outcome

All four source pages were reachable with HTTP 200 after network access was approved for the metadata-only probe.

## Key Findings

- `SRC-CUSTOMS-WELLCOME` provides a strong item-level entry point for customs medical reports.
- `SRC-CMMJ-CRL` provides an item-level entry point for the China Medical Missionary Journal, with a 1894 title signal in the probed record.
- `SRC-SMC-BNASIE` provides an item-level entry point for the 1898 Shanghai Municipal Council report and 1899 budget.
- `SRC-CUSTOMS-AS` provides a live portal entry point for Chinese Maritime Customs materials.

## Changed Assumptions

- The first pilot has enough reachable web entry points for lawful small-sample probing.
- Item-level access is plausible, but bulk reuse remains unproven.

## Failures and Blockers

- Initial sandboxed probe failed with remote-connection errors; the failure was resolved by approved network access.
- No access-control bypass was attempted.
- Bulk access and OCR/text availability are still unresolved.

## Follow-up Tasks

- T31 should probe OCR/text quality and download mechanisms only for open or permission-compatible item-level materials.
- T41 should keep benchmark items small and source-cited.
