## 执行摘要

本轮没有扩张史料规模，而是审计上一轮20题到底测量什么。结论是：原题组主要是历史文献阅读、来源范围控制、作者断言与现代事实分离、证据不足和认识论校准，并不是成熟的“时代错置”测试。严格按主要测量目标计，只有 Q017 直接区分出版时间、观察时间和知识截止时间；没有一道题已经具备独立年代依据，可直接把模型输出判作“引入截止日后的知识”。20题分为10题可直接用于研究验证、2题需修改、7题仅作阅读控制、1题暂不适合；它们只对应11个证据独立组，且9题存在高或很高措辞提示风险。

本轮冻结原题与 B0/B1/B2，另建了 E0/E1/E2/E3 的 2×2 因子协议，将明确时间截止提示与核验 Oracle 史料作为两个独立操控。排除需要图像的 Q007 和缺少说话者上下文的 Q012 后，生成18题×4条件=72个完整 Prompt packet，均有哈希。评分改为八个独立维度，不再压成单一总分；时代错置判定必须同时具有输出片段、独立年代证据、截止点和行动者可达性。

已为12个核验段落和20题生成随机化盲核材料、分歧队列与空白评分账本，但独立复核完成数仍为0。环境复查未发现可控本地模型命令或已配置授权接口，因此没有调用付费/未知额度 API，也没有真实模型输出或性能结论。当前最可靠的硕士论文主线应转向“历史史料来源忠实性与认识论校准”，并用一组新建、独立年代证据支持的小型时代错置模块扩展；联合建模只有在真实基线显示稳定缺陷后才值得开展。

## 1. Phase A：20题构念审计

### 1.1 数量结论

| 审计维度 | 结果 |
|---|---:|
| 原始题目 | 20 |
| 证据独立组 | 11 |
| 可直接用于研究验证 | 10 |
| 需要修改 | 2（Q012、Q016） |
| 只能用作控制题 | 7 |
| 暂不适合当前主实验 | 1（Q007） |
| 主要目标直接涉及历史时间/知识边界 | 1（Q017） |

| 高或很高措辞提示风险 | 9 |

这里的“可直接用于研究验证”不等于时代错置题：其中多数测来源范围、归因、限定语、证据不足和历史断言—现代真值分离。逐题依据见 `audit/ITEM_AUDIT_REPORT.md`。

### 1.2 关键题目问题

- Q007 的标准答案依赖扫描图像与原 OCR 的 5,807/6,807 冲突，放入纯文本四条件实验会改变输入模态，应保留为独立 OCR 多模态控制。
- Q012 的孤立证据没有说话者身份，暂时不能公平评分归因；必须补周边页再重审。
- Q016 原金标准包含核验摘录之外的方法，修订稿已只保留明矾与谨慎过滤。
- Q004、Q008/Q009、Q012/Q013、Q016 有潜在年代研究价值，但相应年代事实仍未核验，登记为4项 chronology gap，禁止使用时代错置标签。
- 7道普通阅读题可验证模型是否能读懂 Oracle，不能用于宣称模型理解了历史知识边界。

## 2. Phase B：可解释的 E0/E1/E2/E3 实验

| 条件 | 明确历史截止 | 核验 Oracle | 主要解释 |
|---|---:|---:|---|
| E0 | 否 | 否 | 默认回答、参数记忆、猜测或拒答 |
| E1 | 是 | 否 | 时间提示的增量影响 |
| E2 | 否 | 是 | Oracle 的增量影响 |
| E3 | 是 | 是 | 联合条件及可能交互 |

四组对同一修订题目、模型和生成参数保持一致；E1/E3 只增加同一截止条款，E2/E3 只增加同一 Oracle 块。Oracle 仅含书目信息、页码/观察期和核验原文，不含金答案、现代释义或注意事项。72个 packet 使用固定随机种子并保存规范化 SHA-256。

可以独立比较两个因素，但解释有边界：没有 Oracle 的 E0/E1 对冷门来源问题主要测参数记忆、校准和幻觉，不能把“不知道”自动计错；时间提示的历史有效性目前只能在 Q017 做个案判断。计划比较 E1−E0、E3−E2、E2−E0、E3−E1，并按11个证据组报告配对转变，不把18题当18个独立样本，也不做夸大的显著性结论。

## 3. Phase C：核验与评价体系

评分账本保留八个独立字段：史料事实准确性、时间边界、来源归因、证据忠实性、无依据内容、认识论校准、断言—真值分离、拒答行为。只有 E2/E3 可直接评分 Oracle 忠实性；时间违规若没有独立年代卡则记 `unscorable`，不能从 Oracle 缺失反推时代错置。

本轮已生成12条段落盲核任务、20条题目盲核任务和分歧队列。10条段落被列为高优先级，涉及数字、日期、医学术语、已知 5,807/6,807 冲突或说话者上下文。当前 `independent_reviews_completed=0`：同一 Codex 对自身产物的再次检查只算自动交叉检查，不能冒充独立盲核或史学专家裁决。

四个命题被强制分栏：知识何时存在、特定行动者是否可能接触、某份档案是否记录、模型是否实际使用后世知识。争议题允许多种可接受答案；没有可靠现代真值证据时，只评分模型是否正确归因历史断言。

## 4. Phase D：模型实验状态

推理基础设施已经就绪：通用 OpenAI-compatible 脚本支持干运行、条件/题目筛选、追加式原始输出、逐条落盘、失败停止和断点续跑。默认只访问回环地址；远程执行必须显式 `--allow-remote` 并使用已授权密钥环境变量。

实际环境中未发现 `ollama`、`llama-server`、`lmstudio` 或 `llamafile`，也未发现相应凭证变量名。按禁止擅用付费或未知额度 API 的约束，本轮真实调用数为0、模型输出数为0。干运行验证了4个 packet 的选择流程且未创建伪输出文件。因此不能报告 E0—E3 的任何性能、时代错置率或 Oracle 增益。

## 5. 当前可检验假设

### 已具备运行条件（待合法模型接口）

1. Oracle 是否提高史料事实准确性和限定语忠实性。
2. 无 Oracle 时模型是否用错误自信替代对冷门来源的不确定性。
3. 时间提示是否改变拒答、校准或无依据扩展，即使尚不能把变化解释成真实时代错置改善。
4. Oracle 是否帮助来源归因，或反而使模型把历史作者断言提升为现代事实。
5. 在 Q017 个案上，模型能否区分出版、观察和知识截止时间。

### 当前不能可靠检验

1. 模型是否系统性引入截止日之后才出现的知识、术语或制度。
2. 某知识何时首次进入晚清中国，或某历史行动者实际能否接触。
3. 某病何时首次在特定地区出现、全社会是否知道某项知识。
4. 1880—1899 年内部的知识边界变化；当前材料只覆盖1884、1889、1890且来源集中。
5. 新时间—证据联合模型是否必要；还没有真实失败模式作为方法动机。

## 6. 研究方向复评

| 方向 | 当前数据支撑 | 论文适配 | 判断 |
|---|---|---|---|
| A 历史知识边界与时代错置 | 弱：严格时间题1，直接后世侵入题0 | 补齐专门题组后高 | 保留为小型严格模块，不宜用当前20题单独立论 |
| B 来源忠实性与认识论校准 | 最强：10题可直接研究、7题可作控制 | 高 | 建议作为主线 |
| C 时间约束与外部证据联合建模 | 协议已就绪，行为证据为0 | 条件性 | 先跑基线；只有稳定交互或失败时再做方法 |

方向 B 与通用 RAG 的区别应明确写成：不仅看答案是否与片段一致，还看模型是否保留历史说话者、限定语和档案范围，是否把断言误当现代事实，是否把“不记载”误当“不存在”。方向 A 的原创性则取决于独立年代证据和行动者范围，而不是给普通问答加一句“请站在1889年”。

## 7. 下一轮最小依赖顺序

1. **独立盲核（硬门槛）：**由非本轮生成者复核12段、20题及可接受答案，先处理数字/日期/说话者和 Q016 金标准。
2. **取得可控接口：**优先本地或明确授权、可记录精确模型版本的接口；先对8题 primary set 跑32个 packet，再决定是否扩到72个。
3. **双因素描述性分析：**按证据组报告八维错误转变，不合成总分；先判断任务是否过易、提示是否泄漏。
4. **定向补4—8题时代错置题：**每题先建年代卡与行动者可达性，再写题；优先补1890年代后期及中文/不同机构来源。
5. **方法分支门槛：**只有观察到可复现的时间违规、证据误用或二者交互，才启动方向 C；暂不做 RAG、大规模 OCR、微调或训练。

## 8. Q1—Q6 明确回答

### Q1：现有20道题中，真正直接测试历史知识边界或时代错置的有多少？

严格计数为 **1题（Q017）**，它测出版时间、观察时间与知识截止时间的区分。**直接测试并可判定后世知识侵入的为0题**。其余主要是7题普通阅读控制和12题来源范围、归因、证据不足、断言—真值或证据忠实性题，其中2题尚需修改、1题不适合纯文本主实验。

### Q2：时间提示和 Oracle 能否作为独立因素比较？

**在提示设计层面可以。**E0/E1/E2/E3 是平衡2×2设计，且只改变相应条款。不过时间因素的“历史知识边界”解释目前很弱：多数题没有独立年代依据，因此可先解释为时间提示对回答行为/校准的影响，不能普遍解释为时代错置率变化。

### Q3：哪些假设可实测，哪些仍缺题或史料？

可实测 Oracle 对事实、限定语、归因和校准的影响，时间提示对拒答/错误自信的影响，以及 Q017 的时间层次辨析。不能实测系统性后世知识侵入、行动者可达知识、首次出现、社会普遍认知和1880—1899内部变化；这些都缺独立年代证据、跨来源材料或专门题目。

### Q4：模型表现很好时，怎样区分题目过易和原假设不成立？

先看7道阅读控制与构念题的差距，再看 E0→E2 是否出现大幅提升。若仅 E2/E3 高，说明有证据阅读容易，不能否定历史边界缺陷；若提示词本身泄漏拒答方向，应改为中性最小对、加入未见来源和反直觉限定语。只有模型在独立年代支持、低提示泄漏、跨来源的专门时代错置题上，E0/E1 都稳定正确，才真正削弱原假设。

### Q5：模型出错时，能否区分四类错误？

**前三类可以按现有框架区分，时间错误有条件。**普通阅读错误由核验文本判；来源归因错误由说话者/机构上下文判；证据利用错误在 E2/E3 由 Oracle 与输出片段判。时间知识错误必须另有年代卡、截止点和行动者范围，否则只能记无依据内容或 `unscorable`，不能强判时代错置。

### Q6：高质量硕士论文下一步最值得投入什么？

把 **方向 B“历史史料的来源忠实性与认识论校准”作为主线**，立即完成独立核验并跑小型 E0—E3 基线；同时用少量高质量工作补建方向 A 的年代证据题组。不要先做新架构、Historical RAG 或大规模数据扩充。方向 C 只在基线证明确有稳定、可复现且现有提示/证据不能解决的缺陷后启动。
