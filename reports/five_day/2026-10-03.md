## 1. 文献变化

### 直接影响当前贡献的核心文献

- "Can Language Models Represent the Past without Anachronism?"  
  来源：https://arxiv.org/abs/2505.00030  
  判断：这是当前课题最直接的竞争与参照工作。它把“语言模型能否表示过去且避免时代错置”作为核心问题，并比较提示、微调和预训练路线。当前项目必须避免只重复“历史模拟/时代错置”问题本身，而要更明确地转向 late-Qing public health、source ecology、historical ignorance 和 provenance-constrained evaluation。

- "Pretraining Language Models on Historical Text"  
  来源：https://arxiv.org/abs/2606.02991  
  判断：这篇文献强化了历史预训练路线的重要性，也说明继续预训练、泄漏缓解、历史事件评测和来源约束指令调优已经成为正在成形的技术路线。当前项目应继续把 LoRA/DAPT 放在后置路线，先建立小型真实 benchmark 和来源约束评价，否则训练比较缺少评估抓手。

- "ExAnte: A Benchmark for Ex-Ante Inference in Large Language Models"  
  来源：https://aclanthology.org/2026.eacl-long.72/  
  判断：ExAnte 的 ex-ante inference 和 temporal leakage 评价与本项目的“1900年前可知性”高度相关。它提供了可借鉴的 cutoff violation 思路，但当前项目仍可通过历史来源约束、晚清中文公共卫生、历史性无知和档案可达性边界形成差异。

- "HistoRAG: Embedding Historical Methodology in Retrieval-Augmented Generation Through Critical Technical Practice"  
  来源：https://arxiv.org/abs/2606.18103  
  判断：HistoRAG 直接覆盖 historical RAG 的历史方法论嵌入、来源生态和时间分布均衡检索。当前项目如果继续使用 Historical RAG，必须把贡献点从“做一个历史 RAG”转为“评估 RAG 是否减少时代错置、过度确定性和错误来源归属”。

### 有方法参考价值但不是核心竞争的文献

- "Teaching Large Language Models When Not to Know"  
  来源：https://arxiv.org/abs/2605.14636  
  判断：对 historical ignorance 很有价值，尤其是训练/评估模型何时应承认不知道。它可以作为拒答校准和不确定性评价的近邻方法，但不是晚清史料问题本身的替代。

- "A Model of the Language Process"  
  来源：https://aclanthology.org/2026.acl-long.590/  
  判断：它提供了 temporal language modeling 与 anachronism-aware framing 的方法参照。对本项目的启发是：问题构造不能只给出年份角色提示，还应显式区分语言、事实、因果和价值判断层级。

- "Temporal Leakage in LLM Backtesting"  
  来源：https://arxiv.org/abs/2608.02985  
  判断：可借鉴其 leakage measurement 思路，但它不处理历史档案来源可达性和历史材料的证据边界。

- "Source-Aware Reranking for Retrieval-Augmented Generation"  
  来源：https://arxiv.org/abs/2607.22584  
  判断：可作为 provenance-aware retrieval 的轻量方法参照，但需要改造成历史来源生态下的 source-type / source-date / source-community 约束，而不是通用来源可靠性排序。

- TDBench paper  
  来源：https://proceedings.iclr.cc/paper_files/paper/2026/hash/2cbeff05cd646fcc09f6c3c48ba56f74-Abstract-Conference.html  
  判断：对 temporal QA benchmark 生成有方法价值，但不是历史档案或晚清材料。

## 2. 数据生态变化

TDBench 是本轮唯一新增数据/benchmark 候选。它基于 temporal databases 构造 factual time-sensitive QA，对本项目的价值主要是 benchmark 生成方法，而不是直接数据源。

结论：

- 不能作为 late-Qing public-health benchmark 的直接材料；
- 可借鉴“结构化时间数据库 → 时间敏感 QA”的自动生成思路；
- 当前项目仍需要从真实历史段落、元数据和来源群体边界构造小型 benchmark；
- 后续 Five-Day 可检查是否存在公开数据文件、license、schema 和可复用生成脚本。

来源：

## 4. 方法工具变化

### docparse-rs

来源：https://github.com/yzlabai/docparse-rs

判断：

- 优点：单二进制、面向 RAG chunk、page+bbox citation、可输出 JSON/Markdown/Text/chunks，并带 OCR/layout 增强路径；
- 对当前项目的潜在价值：如果能处理扫描 PDF 或已有 OCR 文本，它可帮助建立可引用 chunk，降低 Historical RAG 证据定位成本；
- 风险：需要验证中文/历史 OCR、Windows 可用性、PDF 版面复杂度、许可和模型增强依赖；不能默认替代专门 OCR。

### pageledger

来源：https://github.com/peterbussch/pageledger

判断：

- 优点：面向 OCR 和文档抽取的 page-level run ledger，强调可审计、可复跑、provenance 和历史文档处理；
- 对当前项目的潜在价值：它与“来源约束”和“可追溯证据链”高度契合，可能适合作为 OCR/抽取实验日志层；
- 风险：需要验证成熟度、维护活跃度、与中文/晚清材料的兼容性，以及是否值得引入额外工具复杂度。

## 5. 研究资源是否降低工作量

有两个方向可能降低工作量：

1. Wellcome API 降低史料发现与 metadata 获取成本。
2. docparse-rs / pageledger 降低文档解析、chunk provenance 和 OCR 运行记录成本。

但这些都只是候选工具链，不应立即改造工程结构。下一步应做小型本地 probe，而不是引入完整 pipeline。

## 6. 对当前研究设计的影响

### 贡献增强

- `historical ignorance` 变得更重要：ExAnte 与 "When Not to Know" 说明 cutoff-aware uncertainty 已经是明确问题，但历史档案可达性下的“应不知道”仍有差异化空间。
- `provenance / source ecology` 应继续强化：HistoRAG 与 source-aware reranking 都说明通用 RAG 不够，历史来源生态是关键差异。
- `multi-level anachronism` 仍成立：现有工作覆盖时代错置大方向，但晚清公共卫生中的事实/词汇/因果/价值/来源归属组合仍有空间。

### 贡献受威胁

- “历史语言模型避免时代错置”这个宽泛表述已被高度接近的工作覆盖。当前项目不能把它作为唯一主张。
- “做 Historical RAG”也不是足够新颖的主张；必须落到来源约束、历史性无知和 late-Qing public-health benchmark。

### 数据可行性

- Wellcome API 增强开放英文/西文医学史料可行性；
- 晚清中文报刊、期刊和数据库订阅限制仍未解决；
- TDBench 不改变晚清材料可得性。

## 拟议研究设计变更

以下为建议层，不修改 `CURRENT_RESEARCH_DESIGN.md`：

1. 将正式表述从“Historical RAG 研究”进一步收紧为“来源约束下的晚清公共卫生时代错置与历史性无知评测”。
2. 把 `historical ignorance` 明确拆成两类：模型能力边界不知道；历史来源生态中不可确定/不可得。
3. 把 `source ecology` 从背景风险提升为核心评价维度：同一问题在海关、传教士医学、市政资料中的可答性不同。
4. 在后续 pilot 前增加一个很小的工具探针：Wellcome API + 1 个 PDF/IIIF 样本 + docparse-rs 或 pageledger 的可引用 chunk 试验。
