# 14-Day Strategic Audit 协议

## 触发与目的

仅在调度器选择 `audit` 或手动强制时执行。首次自动到期不早于迁移锚点后14天。旧 `HALF_MONTH` 手动入口是本阶段的显式兼容别名，不沿用旧15日成功时间。

审计科学问题、创新性、评测有效性、方法可行性、跨时期/领域泛化、资源与伦理风险，并生成研究决策包。

## 必须回答

1. 严格验证案例、真实 Baseline 和方法原型各有多少，证据在哪里？
2. 核心创新是否被竞争工作覆盖？M1/M2/M3成熟度及反证是什么？
3. 评测是否存在标签失效、历史可达性混淆、事件级泄漏或来源偏差？
4. 哪些路线继续、暂停、放弃或 blocked？
5. 累积证据是否足以创建新的正式研究设计版本？

## 输出与版本权限

输出 `reports/audit/YYYY-MM-DD.md` 和到期时的 `reports/research_briefs/YYYY-MM-DD.md`。简报仅含真实交付物、证据、主要风险、方法成熟度、下一步建议和最多三个用户决策问题。

只有答案明确为 YES 且证据充分时，才可按以下不可分割顺序升级：冻结当前完整 `RESEARCH_DESIGN.md` 到新 archive 文件 → 生成完整新版 → 更新 `CURRENT.md` → 追加 `VERSION_LOG.md`。必须验证快照、版本号和日志一致后才算成功；失败不得更新 Audit 的 `last_successful`。改变核心问题一律 `needs_review`。
