# 3-Day Tactical Review 协议

## 触发与目的

仅在调度器选择 `tactical` 或手动强制时执行。首次自动到期不早于迁移锚点后3天。

检查 backlog 的验收、失败、阻塞、证据状态、资源使用和 Track A/B 平衡；可调整短期优先级和把依赖已满足的任务从 proposed 提升为 ready，不得修改正式研究设计。

## 成功验收

- 逐项核对最近任务的交付物是否存在、验收是否真实通过；
- 对失败两次且无新修复手段的任务记录分析并标 blocked；
- 识别可安全恢复的 checkpoint 和下一批不超过资源预算的任务；
- 输出 `reports/tactical/YYYY-MM-DD.md`，列出调整前后优先级、阻塞与理由；
- 不把没有产物的任务标 completed，不生成研究结论或虚假实验结果。
