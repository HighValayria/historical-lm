# 项目概览

## 项目身份

- 名称：LLM Historical Anachronism
- 论文类型：计算机相关专业硕士毕业论文
- 主要科学问题：LLM 在给定历史时间与信息条件下的时代错置
- 主要贡献目标：可验证的模型或系统缓解方法
- 当前阶段：Research & Method Feasibility

## 中心决策

方向 A“历史知识边界与时代错置”是主线。方向 B“来源忠实性与认识论校准”保留为辅助任务、控制变量和方法安全性检查。Benchmark 是测量工具，不是最终贡献终点。

## 候选路线

M1 时间条件化参数适配、M2 时间感知检索、M3 时代错置验证 Agent 并行做最小探针；依据真实基线缺陷、可复现效果、算力和数据成本选择深入路线。

## 历史资产

晚清公共卫生数据、20题、冻结 Prompt、OCR/出处链和审计报告完整保留。它们证明了一套可复用基础设施，同时也证明现有题目不足以直接支撑时代错置主张。

## 边界

不做未经证据支持的历史不存在标签，不擅用付费接口，不开始大规模训练，不把单一时期或档案生态泛化为全部历史知识。
