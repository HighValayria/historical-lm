# Task Packet: T21 Score and Select Candidate Directions

## Scope

Score the T20 candidate directions using configured criteria and select a recommended direction plus viable alternatives.

## Files to Read

- `reports/candidate_research_questions.md`
- `state/config.yaml`
- `evidence/literature_matrix.md`
- `evidence/source_registry.md`
- `evidence/concept_map.md`

## Files Allowed to Edit

- `reports/candidate_topic_scorecard.md`
- `reports/recommended_direction.md`
- `reports/nodes/T21.md`
- `evidence/evidence_map.md`
- `logs/task_journal.md`
- `decisions/DECISIONS.md`
- `assumptions/ASSUMPTIONS.md`
- `state/run_state.json`

## Scoring Dimensions

Use 1-5 for:

- digital_humanities_value
- novelty
- data_feasibility
- evaluation_clarity
- compute_feasibility
- value_if_results_are_negative

## Completion Criteria

- All candidates scored.
- One recommended direction selected.
- Viable alternatives and rejected/deferred directions identified.
