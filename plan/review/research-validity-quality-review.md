# Research Validity Pilot — Quality Review

Date: 2026-10-13
Reviewer: Codex primary agent (self-review)

## Strengths

- The main negative finding is explicit: the current set does not substantiate a broad anachronism benchmark.
- Factor changes are mechanically isolated and testable; prompt hashes and run order are fixed.
- Evidence absence, actor access, knowledge existence and model use are represented as different propositions.
- The scoring system keeps error families independent and defines a high evidence threshold for temporal violations.
- Output/status files make zero model execution and zero independent review auditable.

## Residual quality risks

1. Construct annotations and revised wording are still one-agent judgments; independent review may change dispositions.
2. Nine original items had high/very-high cue risk. Revised wording reduces but has not behaviorally validated that risk.
3. E0/E1 source-specific questions confound cold recall with calibration; only condition-aware interpretation makes them fair.
4. Eleven evidence groups are too few for confirmatory statistical claims.
5. The single strict temporal item cannot estimate a general temporal-prompt effect.
6. Source ecology remains English, institutional and uneven in time.

## Decision

**Accept as a high-quality design/audit deliverable; reject any claim that the model hypothesis has been behaviorally confirmed or refuted.** Before thesis-level claims, require independent blind review, real versioned model outputs and a chronology-backed temporal mini-suite.
