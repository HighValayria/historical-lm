# 新项目运行大纲

1. 定义 historical/temporal anachronism、知识有效时间、行动者可达性和判错证据门槛。
2. 调查时代错置评测、时间知识、时间感知检索、参数适配和验证 Agent 的直接相关工作。
3. 建立10—15个跨领域知识年代案例和证据卡，形成最小可信评测。
4. 取得可控模型接口，运行无约束、时间 Prompt、Oracle 与必要反事实控制的 Baseline。
5. 分别实现 M1/M2/M3 最小原型，使用同一评测和独立指标比较。
6. 根据消融、成本、错误覆盖和负结果鲁棒性选择主方法路线。
7. 扩展数据和实验仅服务于已选方法与论文论证链。

晚清公共卫生资料扩张不再是默认前置任务；只有当其能提供严格年代案例、跨来源验证或方法压力测试时才重新进入 active backlog。
